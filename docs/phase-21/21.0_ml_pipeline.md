## STEP 21.1 — Data Collection

**File:** `ml/data_collection.py`

Collects training data from multiple sources.

### Data Sources

| Source | Data | Storage |
|--------|------|---------|
| Leads | Outcome data (replied, booked, converted, no-show) | PostgreSQL |
| Conversations | Message features, intents, sentiments | PostgreSQL |
| Appointments | Timing features, agent features, outcomes | PostgreSQL |
| ClickHouse | Time-series analytics | ClickHouse |

### DataCollector Class

```python
collector = DataCollector(db)

# Collect lead outcomes
outcomes = collector.collect_lead_outcomes(tenant_id, days_back=90)

# Collect conversation features
conversations = collector.collect_conversation_features(tenant_id, days_back=90)

# Collect appointment features
appointments = collector.collect_appointment_features(tenant_id, days_back=90)
```

### Lead Outcome Fields
- replied: bool — Customer replied to outreach
- booked: bool — Appointment was booked
- converted: bool — Appointment was won
- no_show: bool — Customer didn't show up
- response_time_hours: float — Time to first reply

## STEP 21.2 — Feature Engineering

**File:** `ml/feature_engineering.py`

Transforms raw data into ML-ready features.

### Feature Categories

#### Source Features
| Feature | Description |
|---------|-------------|
| quality | Source quality score (0-1) |
| volume | Expected volume (0-1) |
| cost | Relative cost (0-1) |

#### State Features
| Feature | Description |
|---------|-------------|
| market_value | State market value (0-1) |

#### Time Features
| Feature | Description |
|---------|-------------|
| hour_sin | Cyclical hour encoding (sin) |
| hour_cos | Cyclical hour encoding (cos) |
| day_sin | Cyclical day encoding (sin) |
| day_cos | Cyclical day encoding (cos) |
| is_business_hours | Within 10AM-9PM |
| is_weekend | Saturday/Sunday |

#### Response Delay Features
| Feature | Description |
|---------|-------------|
| response_delay_hours | Hours until first reply |
| response_delay_bucket | Categorical (0-4) |
| is_quick_response | Replied within 1 hour |

#### Engagement Features
| Feature | Description |
|---------|-------------|
| total_messages | Message count |
| customer_engagement | Customer message ratio |
| messages_per_hour | Message rate |
| is_highly_engaged | 5+ customer messages |

### Functions
- `extract_source_features(source)` — Source encoding
- `extract_state_features(state)` — State market value
- `extract_time_features(dt)` — Cyclical time encoding
- `extract_response_delay_features(contact, reply)` — Timing features
- `extract_engagement_features(messages, duration)` — Engagement metrics
- `extract_lead_features(lead_data)` — All lead features
- `extract_appointment_features(appt_data)` — All appointment features
- `prepare_training_features(outcomes, conversations)` — Training data prep

## STEP 21.3 — Model Training

**File:** `ml/model_training.py`

Trains models using weighted feature scoring.

### Models

| Model | Target | Features |
|-------|--------|----------|
| Booking Model | booked | Source, time, engagement, lead_score |
| Conversion Model | converted | Source, engagement, lead_score |
| No-show Model | no_show | Response delay, engagement, lead_score |

### Training Process
1. Collect training data
2. Extract features
3. Calculate feature weights (correlation analysis)
4. Save model to file

### ModelTrainer Class
```python
trainer = ModelTrainer(model_dir="models")

# Train models
booking_model = trainer.train_booking_model(X, y)
conversion_model = trainer.train_conversion_model(X, y)
no_show_model = trainer.train_no_show_model(X, y)
```

## STEP 21.4 — Model Evaluation

**File:** `ml/model_evaluation.py`

Evaluates model performance using standard metrics.

### Metrics

| Metric | Formula | Description |
|--------|---------|-------------|
| Precision | TP / (TP + FP) | Accuracy of positive predictions |
| Recall | TP / (TP + FN) | Coverage of actual positives |
| F1 Score | 2 * (P * R) / (P + R) | Harmonic mean of P and R |
| ROC-AUC | Area under ROC curve | Discrimination ability |
| Accuracy | (TP + TN) / Total | Overall correctness |

### Functions
```python
# Single evaluation
metrics = evaluate_model(y_true, y_pred, threshold=0.5)

# Multiple thresholds
results = evaluate_with_multiple_thresholds(y_true, y_pred)

# Find optimal threshold
optimal, value = find_optimal_threshold(y_true, y_pred, metric="f1_score")

# Cross-validation
cv_results = cross_validate(X, y, predict_fn, n_folds=5)
```

### Evaluation Output
```json

    "roc_auc": 0.89,
    "accuracy": 0.82,
```

## STEP 21.5 — Model Deployment

**File:** `ml/model_registry.py`

Manages model versions, deployment, and A/B testing.

### Model Registry

```python
registry = ModelRegistry()

# Register model
model = registry.register_model(
    model_name="booking_model",
    version="1.0.0",
    model_path="models/booking_model.json",
    metrics={"f1_score": 0.81, "roc_auc": 0.89},
)

# Promote to production
registry.promote_model("booking_model", "1.0.0")

# Get production model
model = registry.get_model("booking_model")
```

### Model Status Flow
```
staging → production → archived
```

### A/B Testing

```python
ab_manager = ABTestManager(registry)

# Create test
test = ab_manager.create_test(
    test_name="booking_model_v1_vs_v2",
    model_a="1.0.0",
    model_b="2.0.0",
    traffic_split=0.5,
    metric="f1_score",
)

# Select model for request
version = ab_manager.select_model(test.test_id)

# Record result
ab_manager.record_result(test.test_id, version, metric_value)

# Complete test and get winner
results = ab_manager.complete_test(test.test_id)
```
