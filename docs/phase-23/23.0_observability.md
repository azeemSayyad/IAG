## STEP 23.2 — Dashboards

**File:** `infrastructure/monitoring/grafana/dashboards/api.json`

### Dashboard Panels

#### Request Rate
- Queries: `rate(http_requests_total[5m])`
- Visualization: Time series
- Unit: requests/second

#### P95 Response Time
- Queries: `histogram_quantile(0.95, rate(http_request_duration_seconds_bucket[5m]))`
- Visualization: Time series
- Unit: seconds

#### Error Rate
- Queries: `rate(http_errors_total{status_code=~"5.."}[5m]) / rate(http_requests_total[5m])`
- Visualization: Gauge
- Unit: percentage

#### Active Connections
- Queries: `http_requests_in_progress`
- Visualization: Stat
- Unit: connections

## STEP 23.3 — Distributed Tracing

**File:** `app/core/tracing.py`

OpenTelemetry integration for distributed tracing.

### Features
- Automatic FastAPI instrumentation
- SQLAlchemy query tracing
- Redis operation tracing
- HTTP client tracing
- Celery task tracing
- Custom span creation

### Initialization
```python
from app.core.tracing import init_tracing, instrument_fastapi

# Initialize tracing
init_tracing(
    service_name="launchpad-backend",
    otlp_endpoint="localhost:4317",
    enable_console=True,  # Development only
)

# Instrument FastAPI
instrument_fastapi(app)
```

### Custom Spans
```python
from app.core.tracing import trace_function, trace_operation

# Decorator
@trace_function("my_function", {"key": "value"})
def my_function():
    pass

# Context manager
with trace_operation("my_operation") as span:
    span.set_attribute("key", "value")
    # ... do work
```

### Exporters
- OTLP (gRPC) — For production (Jaeger, Tempo)
- Console — For development

## STEP 23.5 — Centralized Logging

**Files:** `infrastructure/monitoring/elk/`

### ELK Stack Components

#### Elasticsearch
- Version: 8.12
- Storage: 100Gi PVC
- Single-node mode
- Health check: `/_cluster/health`

#### Kibana
- Version: 8.12
- Connected to Elasticsearch
- Ingress: `logs.launchpad.com`
- TLS enabled

#### Filebeat
- Version: 8.12
- DaemonSet (runs on all nodes)
- Collects: `/var/lib/docker/containers/*/*.log`
- Kubernetes metadata enrichment
- Output: Elasticsearch with daily index

### Log Format
```json
{
  "timestamp": "2026-01-15T10:30:00Z",
  "level": "INFO",
  "service": "backend-api",
  "message": "Request processed",
  "request_id": "abc123",
  "user_id": "user456",
  "tenant_id": "tenant789",
  "method": "POST",
  "path": "/api/v1/leads",
  "status_code": 201,
  "duration_ms": 45
}
```

### Log Queries
```
# Find errors
level:ERROR

# Find slow requests
duration_ms:>1000

# Find requests by tenant
tenant_id:"tenant789"

# Find AI errors
service:ai AND level:ERROR
```
