## STEP 26.2 — AI Inference Optimization

**File:** `app/ai/services/inference_optimizer.py`

### Optimization Strategies

#### 1. Response Caching
- Cache key: MD5(prompt + model + temperature)
- TTL: 1 hour (configurable)
- Cache hit reduces latency to <10ms

#### 2. Model Selection
| Task | Low Complexity | Medium | High |
|------|----------------|--------|------|
| Intent | Mistral | Mistral | Llama3 |
| Response | Mistral | Llama3 | Llama3 |
| Summary | Mistral | Mistral | Llama3 |
| Objection | Mistral | Llama3 | Llama3 |

#### 3. Prompt Compression
- Estimate token count
- Truncate older messages
- Keep system prompt intact
- Respect max token budget

#### 4. Request Batching
- Group requests by model
- Process in parallel
- Reduce overhead

### Metrics Tracked
- Total requests per model
- Cache hit rate
- Average latency
- P95 latency
- Token usage

### Functions
```python
# Cache operations
cached = optimizer.get_cached_response(prompt, model)
optimizer.cache_response(prompt, model, response)

# Model selection
model = optimizer.select_optimal_model("intent", "high")

# Prompt compression
system, messages = optimizer.compress_prompt(system, messages, max_tokens=2000)

# Metrics
stats = optimizer.get_inference_stats("llama3")
```
