## STEP 15.0 — Database Layer Architecture

### 15.0.1 — PostgreSQL Responsibilities

PostgreSQL handles all transactional operations:
- User/agent/lead management (models/user.py, models/agent.py, models/lead.py)
- Appointment booking with ACID guarantees (models/appointment.py)
- Campaign configuration (models/campaign.py)
- RBAC and permissions (core/permissions.py)
- Audit logging (models/audit_log.py)
- Row-level security for tenant isolation (core/row_level_security.py)

### 15.0.2 — Redis Responsibilities

Redis handles (core/redis.py):
- Appointment slot locking (distributed locks via SETNX)
- WebSocket pub/sub for realtime updates (realtime/pubsub.py)
- Background job queues: outbound_sms, retries, reminders, followups (ai/services/queue.py)
- API response caching
- Rate limiting counters (security/rate_limiting.py)
- Retry timers and delayed jobs

### 15.0.3 — Qdrant Responsibilities

Qdrant stores (analytics/vector_search.py):
- Conversation embeddings for semantic search
- Lead similarity search
- Message embeddings
- Collections: conversation_embeddings, lead_embeddings, message_embeddings

### 15.0.4 — ClickHouse Responsibilities

ClickHouse handles (analytics/clickhouse.py, infrastructure/clickhouse/schema.sql):
- Large-scale event analytics (events table)
- Campaign performance reporting (campaign_performance table)
- Agent utilization analytics (agent_performance table)
- Historical trend analysis (hourly_metrics, daily_lead_summary materialized views)
- ML feature aggregation (lead_metrics, appointment_metrics, message_metrics)

## STEP 15.9 — Row Level Security

Implemented in core/row_level_security.py:

### Setup
```python
from app.core.row_level_security import setup_rls
setup_rls(engine)
```

### How It Works
1. RLS enabled on all tenant-scoped tables
2. Policy: `tenant_id::text = current_setting('app.current_tenant_id', true)`
3. Middleware sets `app.current_tenant_id` per request
4. Service role bypasses RLS for background workers

### Tables with RLS
- leads
- conversations
- messages
- appointments
- agent_availability
- campaigns
- audit_logs
- agents
