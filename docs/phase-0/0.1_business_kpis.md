# Step 0.1 — Define Business KPIs

## Primary KPI

### Agent Utilization Percentage

**Formula:**

```
Agent Utilization % = (Booked Appointment Time / Available Agent Time) x 100
```

**Target:** 80%+ utilization per agent per day.

**Why this is primary:** Every other system (AI outreach, scheduling, follow-ups) exists to keep agents on calls. This single number captures platform effectiveness.

**Measurement:**
- Tracked per agent, per team, per tenant
- Measured daily, weekly, monthly
- Displayed on admin dashboard in real-time

---

## Secondary KPIs

### 1. Reply Rate

**Formula:**

```
Reply Rate % = (Leads Who Replied / Total Leads Contacted) x 100
```

**What it measures:** Effectiveness of AI outreach messaging.

**Target:** 25%+ reply rate.

---

### 2. Booking Rate

**Formula:**

```
Booking Rate % = (Appointments Booked / Leads Contacted) x 100
```

**What it measures:** End-to-end conversion from outreach to appointment.

**Target:** 10%+ booking rate.

---

### 3. Conversion Rate

**Formula:**

```
Conversion Rate % = (Policies Sold / Appointments Completed) x 100
```

**What it measures:** Agent closing effectiveness.

**Target:** 30%+ conversion rate.

---

### 4. No-show Rate

**Formula:**

```
No-show Rate % = (Missed Appointments / Total Booked Appointments) x 100
```

**What it measures:** Quality of booked appointments and reminder effectiveness.

**Target:** Below 15% no-show rate.

---

### 5. Revenue Per Agent

**Formula:**

```
Revenue Per Agent = Total Revenue Generated / Number of Active Agents
```

**What it measures:** Revenue productivity per agent.

**Target:** Track and improve monthly.

---

### 6. Cost Per Appointment

**Formula:**

```
Cost Per Appointment = (AI Costs + SMS Costs + Infrastructure Costs) / Total Appointments Booked
```

**What it measures:** Operational efficiency of the automated booking pipeline.

**Target:** Below $5 per appointment.

---

### 7. Lead-to-Booking Time

**Formula:**

```
Lead-to-Booking Time = Timestamp(Appointment Booked) - Timestamp(Lead Created)
```

**What it measures:** Speed of the automated pipeline from lead arrival to confirmed booking.

**Target:** Under 2 hours for engaged leads.

---

## KPI Dashboard Requirements

All KPIs must be:

- Real-time updated via WebSocket
- Filterable by date range, agent, campaign, source
- Exportable as CSV
- Visualized with trend charts (daily, weekly, monthly)
