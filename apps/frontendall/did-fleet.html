Engine controls

Automation engine override
Master switch for the same-day pacing engine. Off = exactly today's behavior (nothing is paced or auto-released). On = capacity-sized release + drip run automatically, and the controls below take effect.
Capacity pacing override
Throttle outbound sends to live agent capacity per state.
Fatigue override
Suppress messaging leads that have been contacted too often.
Carrier caps override
Enforce the per-provider caps (4,000/day total · T-Mobile 2,000/day) — block over-cap sends instead of only counting them. Off = observe-only.
T-Mobile dedup override
Block a second text to the same T-Mobile number across providers (no double-sends). Off = observe-only.
Working hours override
Only send during 10 AM–7 PM Eastern, Mon–Fri — hold texts outside the window. Off = observe-only.
